# public_information — 経営者向けセキュリティレポート

AI Trust Systems 株式会社が公開する、**経営者・個人事業主向け**のセキュリティ動向レポートです。情報処理安全確保支援士による情報収集をもとに、最新のセキュリティ情報・インシデント・重大な脆弱性を、わかりやすい言葉でまとめています。

## 構成

2つの読み方を用意しています。目的に合わせてお選びください。

| フォルダ | 内容 | 頻度 |
|---|---|---|
| `reports/exec-simple/daily/` | 経営者向けレポート **簡易版**・日次。要点を短時間で把握（3トピック＋✅CHECK＋一言アクション） | 毎日 朝5時（JST） |
| `reports/exec-simple/weekly/` | 経営者向けレポート **簡易版**・週次（前週のまとめ） | 毎週月曜 朝5時 |
| `reports/exec-full/daily/` | 経営者向けレポート・日次。背景・理由・具体策まで踏み込んだ版 | 毎日 朝5時（JST） |
| `reports/exec-full/weekly/` | 経営者向けレポート・週次（前週のまとめ） | 毎週月曜 朝5時 |

- 日次ファイル: `YYYY-MM-DD.md`
- 週次ファイル: `YYYY-Www.md`（ISO週番号。前週の月〜日が対象）

技術的な詳細（CVE番号・CVSS等）は扱わず、経営判断と自社点検に役立つ要点に絞っています。

## 更新頻度

最新のセキュリティ情報（特に重要な情報）を**毎日**公開し、**毎週月曜**に前週のまとめを公開します。
