# public_information — 経営者向けセキュリティレポート

AI Trust Systems が公開する、**経営者・個人事業主向け**のセキュリティ動向レポートです。情報処理安全確保支援士による情報収集をもとに、最新のセキュリティ情報・インシデント・重大な脆弱性を、わかりやすい言葉でまとめています。

## 構成

| フォルダ | 内容 | 頻度 |
|---|---|---|
| `reports/exec-simple/daily/` | 経営者向け **簡易版**・日次。要点を短時間で把握（3トピック＋CHECK＋一言アクション） | 毎日 朝5時（JST） |
| `reports/exec-simple/weekly/` | 経営者向け **簡易版**・週次（前週のまとめ） | 毎週月曜 朝5時 |
| `reports/exec-full/daily/` | 経営者向け **本格版（詳しい版）**・日次。背景・理由・具体策まで踏み込む | 毎日 朝5時（JST） |
| `reports/exec-full/weekly/` | 経営者向け **本格版（詳しい版）**・週次（前週のまとめ） | 毎週月曜 朝5時 |

- 日次ファイル: `YYYY-MM-DD.md`
- 週次ファイル: `YYYY-Www.md`（ISO週番号。前週の月〜日が対象）

## 版の使い分け

- **簡易版**: まず要点だけ知りたい方向け。短時間で読めます。
- **本格版（詳しい版）**: 背景や「なぜ経営に関わるか」、具体的なチェック項目まで理解したい方向け。

いずれも非エンジニア向けで、技術的な詳細（CVE番号・CVSS等）は扱いません。

## 更新頻度

最新のセキュリティ情報（特に重要な情報）を**毎日**収集・公開し、**毎週月曜**に前週のまとめを公開します。

## 注記

- 各レポートは公開情報（CISA・JPCERT/CC・IPA・各社セキュリティブログ・報道等）をもとに作成した概要です。数値は公表値・報道ベースの概算を含みます。実務判断の前に一次情報での確認を推奨します。
- 本リポジトリの内容は情報提供を目的とするものであり、特定の製品・組織の評価や助言を保証するものではありません。
