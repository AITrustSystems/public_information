# public_information — セキュリティ情報レポート

AI Trust Systems が公開するセキュリティ動向レポートです。情報処理安全確保支援士による情報収集をもとに、最新のセキュリティ情報・インシデント情報・重大な脆弱性を定期的にまとめています。

## 構成

| フォルダ | 内容 | 対象読者 |
|---|---|---|
| `reports/daily/` | デイリーレポート（専門家向け）。ハイライト・新規の重大脆弱性（CVE/CVSS/影響製品/対策）・国内外のインシデント動向・推奨アクション・情報源 | セキュリティ担当者・技術者 |
| `reports/daily-exec/` | 経営者向け「かんたんレポート」。専門用語を避け、やさしい言葉での事象説明と「自社確認ポイント（CHECK!）」付き | 経営者・個人事業主 |
| `reports/annual/` | 年次・複数年の動向総括レポート | 全般 |

各レポートは `YYYY-MM-DD.md` の形式です。

## 更新頻度

最新のセキュリティ情報（特に重要な情報）を毎日収集・公開します。

## 注記

- 各レポートは公開情報（CISA・JPCERT/CC・IPA・各社セキュリティブログ・報道等）をもとに作成した概要です。CVE番号・CVSS値・被害額などの数値は公表値・報道ベースの概算を含みます。実務判断の前に一次情報での確認を推奨します。
- 本リポジトリの内容は情報提供を目的とするものであり、特定の製品・組織の評価や助言を保証するものではありません。
