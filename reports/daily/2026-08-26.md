## 1. 本日のハイライト

1. **企業の基幹ミドルウェア（Oracle WebLogic・SAP・Apache Struts）への攻撃が集中 — 公表数日〜72時間で悪用**
   Oracle HTTP Server / WebLogic Proxy Plug-in のアクセス制御不備 CVE-2026-21962 が悪用され CISA KEV に追加（8/24）、8/25には未認証で重要データにアクセスされる悪用が観測。SAP Commerce Cloud（CVE-2026-58231）は**公表72時間以内**に悪用。Apache Struts 2 の脆弱性もJPCERT/CCが8/25に注意喚起。**基幹業務システムの土台が標的**に。

2. **Cl0pがShellから大量データ窃取を主張、vCenter悪用でBabuk系ランサム展開 — 恐喝活動が活発化**
   Cl0pが石油大手Shellの機密データ窃取を主張（8/19）。中国系APTが前週のVMware vCenter脆弱性を悪用し**Babuk派生ランサムウェア**を展開。新種マルウェア WordlistLoader・SynkLoader も確認され、ランサムグループへのアクセス販売に使われている可能性。

3. **国内OT/組込み機器の脆弱性が相次ぐ — 古野電気の船舶用AIS装置にハードコード認証情報**
   JPCERT/CCが8/26、古野電気製FA-50（簡易型船舶自動識別装置＝AIS）のハードコード認証情報・認証欠如の脆弱性を公表。前週のNEC UNIVERGE IXルータに続き、**国内メーカーのOT/組込み機器**の脆弱性が続く。

## 3. 国内インシデント動向

- 8/23〜8/26で、国内の新規大規模インシデントの公表は本レポート時点で確認されず。
- **古野電気製FA-50（船舶用AIS）**の脆弱性（8/26）に加え、前週のNEC UNIVERGE IXルータと、**国内メーカーのネットワーク/OT機器の脆弱性が連続**。海運・物流・製造など該当機器を使う組織は点検が必要。
- 参考（2026年上半期の重大事案）: 6月に保険会社で約440万人分の契約者情報漏えいの可能性、通信事業者のISP向けメールシステムで最大1,422万件のメール関連情報漏えいの可能性。大量個人データを扱う事業者への攻撃が続く。上半期は「不正アクセス」267件・「マルウェア感染」153件と高水準。
- **地政学リスク**: 8月下旬〜9月のロシア極東軍管区VOSTOK軍事演習に合わせたサイバー攻撃への警戒が指摘されている。重要インフラ・公的機関は監視強化を。
- JPCERT/CCは Apache Struts 2（8/25）・古野電気FA-50（8/26）・Weekly Report（8/26）を公表。IPAはMicrosoft 8月月例（8/12）の適用継続を呼びかけ。

## 4. 海外動向

- **基幹ミドルウェア/アプリサーバーへの攻撃集中**: Oracle WebLogic・SAP Commerce Cloud・Apache Struts と、企業の業務システムの土台が短期間で悪用される。特にSAPは公表72時間以内の悪用で、パッチ猶予がほぼない。
- **ランサムウェア恐喝の活発化**: Cl0pがShellの機密データ窃取を主張（データ暴露型恐喝）。中国系APTがvCenter脆弱性からBabuk派生ランサムを展開。**脆弱性悪用→ランサム**の直結パターンが継続。
- **新種マルウェア**: WordlistLoader・SynkLoader が次段階ペイロードを配送し、ランサムグループへのアクセス販売（IAB＝初期アクセスブローカー）に使われている可能性。
- **国家支援型**: Lazarus（北朝鮮）のWindows afd.sysゼロデイ（CVE-2026-68820）は防衛・航空宇宙企業を標的にしていた。CISA対応期限は8/25。

## 5. 安全確保支援士としての推奨アクション

1. **基幹ミドルウェア/アプリサーバーの緊急パッチ（今週の最重要）**: Oracle WebLogic（CVE-2026-21962）・SAP Commerce Cloud（CVE-2026-58231）・Apache Struts 2 を利用する場合、即時パッチと管理面の露出排除。**公表72時間以内の悪用**を前提に、これら基幹システムのパッチSLAを最短化。
2. **ランサム直結パターンへの備え**: 脆弱性悪用→ランサム展開が定番化。バックアップのオフライン化・復元テスト、EDR、横展開検知を確認。Cl0p型のデータ暴露恐喝に備え、データ最小化と漏えい対応フローを整備。
3. **国内OT/組込み機器の点検**: 古野電気FA-50（AIS）・NEC UNIVERGE IXルータ等、国内メーカー機器の脆弱性が連続。該当機器の棚卸しとベンダー対応の適用、OT機器のインターネット露出排除を。
4. **KEV対応期限の遵守**: Lazarus afd.sys（CVE-2026-68820、期限8/25）、Zimbra（期限8/24）等、期限付きKEVを確実に適用。
5. **地政学リスクの監視強化**: VOSTOK軍事演習に伴うサイバー攻撃・DDoS・情報戦への警戒。重要インフラ・公的機関関連の顧客には監視強化とインシデント対応体制の確認を助言。
