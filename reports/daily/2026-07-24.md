## 1. 本日のハイライト

1. **ニチレイグループへのランサムウェア攻撃 — RansomHouse が犯行声明、個人情報漏えいの可能性**
   7月13日に発生した不正アクセスによるシステム障害について、7月22日にランサムウェア集団「RansomHouse」がリークサイトで犯行を主張。冷蔵倉庫入出庫・冷凍食品出荷業務が停止し、取引先約5,000社に影響。個人情報漏えいの可能性があるとして対象者への個別通知が開始された。

2. **Microsoft SharePoint Server への活発な攻撃キャンペーン継続 — CISA が KEV 追加と強化策を勧告**
   CVE-2026-32201 / CVE-2026-45659 / CVE-2026-56164 / CVE-2026-58644 の組み合わせによる、オンプレミス SharePoint Server への侵害（IIS マシンキー窃取、デシリアライズによる永続化、マルウェア設置）が確認されている。CVE-2026-58644（CVSS 9.8、未認証RCE）は 7月16日に CISA KEV カタログへ追加済み。

3. **Oracle 7月 Critical Patch Update — 1,449 件のパッチ、CVSS 10.0 が10件**
   7月21日公表。約600件が未認証のリモート攻撃で悪用可能。Java SE を含む32製品ファミリーが対象で、IPA も7月22日に Oracle Java の脆弱性対策情報を公開している。

## 3. 国内インシデント動向

- **ニチレイグループ**（7/13発生・7/22犯行声明）: 上記ハイライト参照。低温物流の停止がケンタッキーフライドチキン、イオン、くら寿司、江崎グリコ等の欠品・遅延に波及し、サプライチェーン影響の典型例となった。
- **村田土地建物（村田製作所グループ）**（7/13公表）: IT環境への不正アクセスにより顧客情報が漏えい。
- 7月第3週も不正アクセスによるシステム障害・情報漏えい・ランサムウェア被害が複数の国内企業で同時多発。攻撃対象は大企業本体からサプライチェーン全体（物流・子会社・取引先）へ拡大する傾向が継続。
- JPCERT/CC は 6/23 に Fortinet 製品の情報漏えいに関する注意喚起も公開しており、境界機器の管理状況の点検が引き続き重要。

## 4. 海外動向

- **SharePoint 攻撃キャンペーン**: 侵入後に IIS マシンキーを窃取し、パッチ適用後も有効な認証済みリクエスト偽造・永続化を図る手口が報告されている(Resecurity、Rapid7 等)。対象はサポート中の全オンプレ版（Subscription Edition / 2019 / 2016）。
- **RevolutionParts.com**（7/22報道）: 自動車ディーラー向け EC プラットフォームで500万件超のレコードが漏えい。
- CISA は 7/14 に SharePoint の強化（ハードニング）を促すアラートを公表。Microsoft Defender / AMSI の検知活用を推奨。

## 5. 安全確保支援士としての推奨アクション

1. **SharePoint（オンプレ）を利用する組織への緊急対応支援**: 7月更新の適用確認に加え、侵害兆候（Webシェル、機微な IIS マシンキーの窃取痕跡）のハンティングを実施。パッチ適用「後」でもマシンキー流出があればキーのローテーションが必要。
2. **月例パッチ運用の確認**: Microsoft 7月更新（特に AD FS の CVE-2026-56155）と Oracle CPU（Java SE 含む）の適用計画を確認。CISA KEV 掲載 CVE は SLA を設けて優先対応。
3. **サプライチェーン・物流系のBCP点検**: ニチレイ事例を踏まえ、物流・倉庫システム停止時の業務継続手順、取引先への影響連鎖と代替手段を確認。委託先・グループ会社（不動産子会社等）のセキュリティ統制も監査対象に。
4. **漏えい時対応の再確認**: 個人情報漏えいの可能性がある場合の個人情報保護委員会への報告（速報3〜5日以内・確報30日/60日以内）と本人通知のフローを確認。
