## 1. 本日のハイライト

1. **Check Point SmartConsole の認証バイパス CVE-2026-16232（CVSS 9.1）が実環境で悪用 — CISA KEV 追加**
   未認証のリモート攻撃者が管理サーバーへ完全な管理者権限で認証でき、セキュリティポリシー・構成の改変が可能。管理サーバーが乗っ取られるとファイアウォール群の制御点を奪われる。7/22公開の Jumbo hotfix を適用し、Trusted Clients（GUIクライアント）を信頼IPに限定することが必須。

2. **GitLab（自己管理型）の RCE 実証コードが公開 — CVE 未採番のまま悪用リスク**
   6/10のパッチ（Oj 3.17.3 更新、セキュリティ修正として扱われず）で塞がれた欠陥について、7/24に depthfirst が動作する実証コードを公開。プロジェクトへ push 可能な認証済みユーザーが `git` 権限でコマンド実行可能。CVE・CVSS が付与されていないため見落とされやすい。

3. **SharePoint 攻撃キャンペーンの継続 — CVE-2026-50522（CVSS 9.8）等が KEV 追加**
   7/22に Microsoft SharePoint のデシリアライズRCE CVE-2026-50522（未認証・CVSS 9.8）が CISA KEV に追加。7月月例（CVE-2026-58644/56164/56155）から続く SharePoint 狙いの攻勢が継続。

## 3. 国内インシデント動向

- **前回のニチレイグループ事案（7/13発生・RansomHouse）** は、報道ベースでバックアップを活用し7/17から業務を順次再開。事前のバックアップ・復旧計画が奏功した事例として引き続き注目。個人情報漏えいの可能性については個人情報保護委員会への報告済み。
- 7/24〜7/26の週末にかけて、国内で新規の大規模インシデントの公表は本レポート時点で確認されず（週末のため公表が翌週にずれる可能性あり）。委託先・グループ会社経由の不正アクセスが引き続き主要な侵入経路との傾向は継続。
- IPA・JPCERT/CC の注意喚起は7月月例（Microsoft・Oracle Java）が最新。新規の緊急注意喚起は確認されず。

## 4. 海外動向

- **Check Point SmartConsole（CVE-2026-16232）**: Rapid7・The Hacker News・Security Affairs 等が一斉に報道。Check Point は「ごく少数の顧客で悪用」と説明するが、境界防御製品の管理面の侵害は影響が甚大。ネットワーク境界機器の管理インターフェースをインターネットに露出させない設計原則が改めて問われる。
- **GitLab PoC 公開**: CVE 未採番・「バグ修正」扱いのため未更新サーバーが多数残存する懸念。開発基盤（GitLab/CI）の侵害はサプライチェーン侵害に直結するため優先度は高い。
- **SharePoint 攻撃**: 7月を通じて continued exploitation。オンプレSharePoint運用組織は侵害後対応（MachineKey ローテーション、永続化痕跡ハント）まで想定が必要。

## 5. 安全確保支援士としての推奨アクション

1. **境界・管理面の緊急点検**: Check Point 管理サーバー（SmartConsole）の hotfix 適用状況を確認。管理インターフェースがインターネットに露出していないか、Trusted Clients が信頼IPに限定されているかを点検。他社製FW/ADCの管理面も同様に露出確認を。
2. **GitLab 自己管理環境の更新**: CVE未採番のため脆弱性管理ツールで拾えない可能性。バージョンを直接確認し 18.10.8 / 18.11.5 / 19.0.2 以降へ。開発基盤はサプライチェーンの起点として優先対応。
3. **SharePoint（オンプレ）継続対応**: 7月累積更新の適用に加え、CVE-2026-50522 追加を踏まえた侵害調査。パッチ適用後もMachineKey流出の可能性があればキーをローテーション。
4. **KEV 連動の運用**: CISA KEV 追加 CVE（今週は Check Point・SharePoint）を社内SLAで優先対応する運用を徹底。「CVE番号が付かない脆弱性」（GitLab事例）も見落とさない情報収集体制を。
5. **週明けの国内公表に注意**: 週末発生のインシデントは翌週公表される傾向。月曜の続報チェックを推奨。
