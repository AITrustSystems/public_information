## 1. 本日のハイライト

1. **Cisco Identity Services Engine（ISE）の CVSS 10.0 脆弱性 CVE-2026-76460 が実環境で悪用 — 認証基盤が標的**
   企業のネットワークアクセス制御・認証を司る Cisco ISE に最高評価（CVSS 10.0）の脆弱性。**認証基盤そのものの侵害は全社のアクセス制御を崩す**。あわせて Check Point Security Management/Log Server の root権限RCE、SolarWinds Access Rights Manager の未認証RCE（CVE-2026-28326、CVSS 8.8）も。**「守るための製品」が狙われる**構図が継続。

2. **Linux Kernel の脆弱性3件が悪用され CISA KEV追加 — サーバー基盤の権限昇格リスク**
   CVE-2025-39682／CVE-2025-39964／CVE-2026-53266 の3件が悪用確認。いずれもローカル権限昇格・DoS。**サーバーOSの土台**が標的で、侵入後の権限奪取に使われる。

3. **国内は医療・半導体サプライチェーン・農協へ被害拡大 — ランサム感染率45.8%**
   2026年の国内はランサム感染率45.8%（JIPDEC調査）。医療機関・半導体サプライチェーン企業・農業協同組合（JA）など、**社会インフラ性の高い組織**へ被害が拡大。前週の鳥取県・T&K TOKA等に続く傾向。

## 3. 国内インシデント動向

- 9/16〜9/20で国内の新規大規模インシデントの公表は本レポート時点で確認されず（医療・半導体・農協系の続報に注意）。
- **社会インフラ性の高い組織への拡大**: 2026年は医療機関・半導体サプライチェーン・農業協同組合（JA）など、止まると社会影響の大きい組織への被害が目立つ。ランサム感染率は45.8%（JIPDEC「企業IT利活用動向調査2026」）。
- **Cisco ISE・Check Point・SolarWinds・Linux は国内でも広く利用**。認証基盤（Cisco ISE）とサーバーOS（Linux）は影響範囲が広く、優先対応が必要。
- IPA「経営者向けランサムウェア対策ハンドブック」（前週公表）の活用と、10大脅威2026の徹底が引き続き重要。

## 4. 海外動向

- **セキュリティ・認証管理製品への攻撃集中**: Cisco ISE（CVSS 10.0）、Check Point 管理サーバー、SolarWinds ARM。**「セキュリティを守るための製品」自体が最高価値の標的**。侵害されれば全社のアクセス制御・権限管理が崩れる。
- **Linux Kernel の実環境悪用**: 3件がKEV追加。サーバー基盤の権限昇格として侵入後に多用される。
- **エネルギー・重要インフラ**: CenterPoint Energy（米エネルギー）が今週最も深刻な侵害。重要インフラの標的化が継続。
- **ランサム統計**: 直近7日で約770万レコード露出、恐喝系が今週の被害主張229件。Feral Wolf等が公開業務ソフト・脆弱なサーバー設定を悪用。

## 5. 安全確保支援士としての推奨アクション

1. **認証・セキュリティ管理製品の緊急点検（今週の最重要）**: Cisco ISE（CVE-2026-76460、CVSS 10.0）、Check Point 管理サーバー、SolarWinds ARM（CVE-2026-28326）を即時更新。**認証基盤の管理インターフェースは絶対にインターネット露出させない**。侵害時は全社のアクセス制御崩壊を想定した対応を。
2. **Linux サーバーの権限昇格対策**: KEV追加の3件を適用。カーネル更新に加え、最小権限・セグメンテーションで侵入後の権限奪取を抑止。
3. **社会インフラ性組織の重点支援**: 医療・半導体・JA等の顧客には、事業停止時の社会影響を踏まえたBCP・バックアップ・多層防御の点検を優先。IPA経営者向けハンドブックを活用。
4. **KEV連動の高速適用（継続）**: Cisco ISE・Linux Kernel等を最短SLAで。CVSS 10.0・認証基盤は即日対応を。
5. **公開業務ソフト・サーバー設定の点検**: Feral Wolf等が弱い設定を悪用。外部公開資産の棚卸し、不要ポート閉塞、初期設定・弱パスワードの排除を。
