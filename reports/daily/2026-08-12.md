## 3. 国内インシデント動向

- 8/9〜8/12（お盆期間）で、国内の新規大規模インシデントの公表は本レポート時点で確認されず（お盆・夏季休暇で公表が遅れる可能性あり。**長期休暇は攻撃者に狙われやすく、検知・対応が遅れやすい**点に注意）。
- **Fortinet 製品は国内でも境界機器として広く普及**しており、Gunra が悪用する CVE-2025-24472/CVE-2024-55591 は国内組織にも直接影響。境界機器の緊急点検が必要。
- Windows 8月月例（DNS Server のワーム化し得るRCE、afd.sysのゼロデイ）は国内の全Windows環境に影響。お盆明けの適用計画を。
- IPA・JPCERT/CC は例年どおり長期休暇前後の注意喚起（システム管理者向けの対策・連絡体制の確認）を発信する時期。

## 4. 海外動向

- **重要インフラ狙いのランサムウェア国家連携対応**: Gunra への米韓等の合同勧告（AA26-222A）は、境界機器の既知脆弱性→ランサムという定番の攻撃経路を国家レベルで警告。Conti系コードの流用でRaaS化が進む。
- **国家支援型のゼロデイ悪用**: Lazarus（北朝鮮）が Windows afd.sys ゼロデイでカーネルルートキットを展開。ゼロデイ×国家支援型の脅威が継続。
- **ランサムウェアの防御回避高度化**: DeadLock が Windows Defender・バックアップ・イベントログを無効化してから暗号化する挙動を確認（8/11）。バックアップとログの保護（改ざん防止・オフライン化）の重要性が増大。

## 5. 安全確保支援士としての推奨アクション

1. **Windows 8月月例の迅速適用（最優先）**: 悪用中の CVE-2026-68820（afd.sys）と、ワーム化し得る CVE-2026-62878（DNS Server）を最優先。特にインターネット公開/内部の DNS サーバーは緊急対応。PoC公開後48時間以内の悪用が常態化している前提で。
2. **Fortinet 境界機器の緊急点検**: Gunra が悪用する CVE-2025-24472/CVE-2024-55591 の適用状況を確認し、未適用なら即時対応＋侵害調査（不正な管理者アクセス、MFA回避の痕跡）。合同勧告AA26-222AのIoC・対策を参照。
3. **バックアップ・ログの保護強化**: DeadLock等がバックアップ・ログを無効化してから暗号化する手口に対し、バックアップのオフライン化・イミュータブル化、ログの集約・改ざん防止を徹底。
4. **長期休暇（お盆）対応**: 休暇中の監視・連絡体制、緊急時対応手順、休暇前後のパッチ適用計画を確認。長期休暇明けは侵害の発覚が集中しやすいため、復帰時の点検を助言。
5. **境界・管理製品の継続対応**: Cisco ASA/FTD（CVE-2026-20349）、Progress LoadMaster、Metabase等のKEV追加分を社内SLAで優先対応。
