## 1. 本日のハイライト

1. **CISAがKEVに6件を一括追加（8/26）— NetScaler・Linux Kernel・JFrog Artifactory・SQL Server が悪用中**
   Citrix NetScaler（CVE-2026-8452、悪用継続）、Linux Kernel（CVE-2026-53362）、開発成果物管理の JFrog Artifactory（CVE-2026-66384、パストラバーサル）、SQL Server 等を一括追加。FCEB機関への対応期限は一部8/29・残り9/9。**OS・開発基盤・DBまで攻撃対象が横断**。

2. **ファイル共有・印刷サーバーのゼロデイ悪用 — ownCloud（核関連記録の窃取）とPaperCut**
   ファイル共有ソフト ownCloud の重大脆弱性が悪用され、**フィリピンの研究機関から核関連記録が窃取**されCISA KEVに追加（8/28）。印刷管理 PaperCut は全サポート版（NG/MF）に影響するゼロデイの実環境悪用を確認（大学のフォレンジックチームが発見）。**社内の「共有・出力の要」が標的**に。

3. **国内で大規模漏えい・ランサムが続く — 名鉄協商のランサム被害、アフラック/KDDIの大規模漏えい**
   駐車場事業の名鉄協商がランサムウェアで顧客情報漏えいの可能性。8月はアフラック（約438万人）・KDDI（約1,223万件）の大規模個人情報漏えいも報告。**規模・業種を問わない標的化**が国内でも継続。

## 3. 国内インシデント動向

- **名鉄協商（駐車場事業）**: ランサムウェアによる不正アクセスで顧客情報漏えいの可能性。物流・サービス業のサプライチェーン型被害が継続。
- **アフラック（約438万人）・KDDI（約1,223万件）**: 8月に大規模な個人情報漏えいが報告。大量個人データを扱う保険・通信事業者への攻撃が続く。
- **傾向**: 2026年上半期は「不正アクセス」267件・「マルウェア感染」153件と高水準。ランサム＋委託先/サプライチェーン経由の漏えい＋人的事故が同時多発。
- 前週から継続: 古野電気FA-50（船舶AIS）・NEC UNIVERGE IXルータ等、国内メーカー機器の脆弱性への対応。
- IPAはMicrosoft 8月月例（8/12）・夏休み注意喚起の継続を、JPCERT/CCはNetScaler（CVE-2026-8452）等を注意喚起。

## 4. 海外動向

- **ファイル共有・開発・印刷基盤への攻撃集中**: ownCloud（ファイル共有）、JFrog Artifactory（開発成果物）、PaperCut（印刷管理）と、社内の「共有・配布・出力」を担う基盤が標的。ownCloudでは核関連記録が窃取され、機微情報の集積地が狙われる構図。
- **OS・DB・境界の横断的悪用**: Linux Kernel・SQL Server・NetScaler がKEV一括追加。攻撃対象がOS・DB・境界機器まで広範化。
- **大規模漏えい**: Manchester Airports Group（英空港運営）で約870万人分のデータ侵害。交通・空港インフラの大量個人データが標的。
- **AIエージェントによる悪用**: JFrog脆弱性がAIエージェント経由で悪用されたと報じられ、攻撃の自動化・高速化が継続。

## 5. 安全確保支援士としての推奨アクション

1. **ファイル共有・印刷・開発基盤の緊急点検（今週の最重要）**: ownCloud・PaperCut・JFrog Artifactory を利用する場合、ベンダー緊急情報に従い即時対処し、管理面・サーバーのインターネット露出を排除。これらは機微情報が集まる/配布される基盤のため、侵害の影響が大きい。
2. **KEV一括追加分の期限遵守**: NetScaler（CVE-2026-8452、対応期限8/29）を最優先に、Linux Kernel・SQL Server・JFrog等を社内SLA（残りは9/9目安）で適用。
3. **大規模個人データ保有組織の防御強化**: 保険・通信・交通など大量個人データを扱う組織は、境界・認証・アクセス制御の多層防御と、漏えい時の報告フロー（個人情報保護委員会）を再点検。
4. **国内OT/機器の対応継続**: 古野電気FA-50・NEC UNIVERGE IX等、国内メーカー機器の脆弱性対応を継続。OT機器のインターネット露出排除。
5. **AIエージェント悪用への警戒**: 攻撃側がAIで脆弱性探索・悪用を自動化する傾向。自組織の公開資産の棚卸しと、パッチ適用の高速化（公表数日での悪用が前提）を徹底。
