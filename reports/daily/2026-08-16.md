## 1. 本日のハイライト

1. **Citrix NetScaler ADC/Gateway の未認証RCE CVE-2026-8452（CVSSv4 8.8）— PoC公開、悪用の可能性「高」**
   Gateway（SSL VPN/ICA Proxy等）またはAAA仮想サーバー構成時に、認証なしでroot権限のパケット処理エンジン（nsppe）を制御され、リモートコード実行の恐れ。WatchTowr Labsが実証コードを公開、NHS England は「悪用の可能性が高い」と評価。JPCERT/CCも8/15に注意喚起。過去のCitrixBleedを想起させる境界機器の重大脆弱性。

2. **VMware vCenter・Windows DNS Server 等、重要基盤の重大脆弱性が集中 — vCenterは公表5日後に悪用**
   Broadcomが公表した vCenter の重大脆弱性が**公表からわずか5日後（8/13）に悪用**。Windows DNS Server には CVE-2026-62878（CVSS 9.8）ほか複数の重大RCE。Metabase の SQLインジェクション CVE-2026-72898（CVSS 10.0）も悪用確認・KEV追加済み。仮想化基盤・DNS・管理ツールが標的。

3. **国内で「盗まれたID」と「サポート詐欺」による被害が続出 — 侵入経路の約8割が認証情報悪用**
   7月の検証済みランサム被害は964件、**侵入経路の約8割が脆弱性ではなく「盗まれたID」**。国内でもヨネックスがリスト型攻撃で個人情報閲覧被害、東京ガス子会社が顧客情報2万件入りPCを紛失、葬祭事業者が**AIツール検索中の「サポート詐欺」**で業務PCを遠隔操作され約4,000ファイル削除。

## 3. 国内インシデント動向

- **ヨネックス**: 盗まれたID・パスワードを使った**リスト型攻撃**で個人情報が閲覧される被害。→ パスワード使い回しと多要素認証未設定が背景。
- **東京ガス子会社**: 顧客情報2万件を含むPCを従業員が帰宅途中に紛失。→ 端末の暗号化・持ち出しルールの重要性。
- **葬祭事業者**: **AIツールを検索中に「サポート詐欺」**（偽の警告画面）に遭遇し、業務用PCを遠隔操作され約4,000ファイルを削除される被害。→ AI活用の広がりとともに、検索起点の詐欺リスクが顕在化。
- **傾向**: 7月の検証済みランサム被害964件、侵入経路の約8割が「盗まれたID」。脆弱性対策と並んで**認証情報の保護（MFA・パスワード管理）**が最重要に。
- **8/15終戦記念日前後**: 安全保障関連の記念日にはDDoS攻撃・情報戦/認知戦の懸念。重要インフラ・公的機関は警戒を。
- IPAは「2026年度 夏休みにおける情報セキュリティに関する注意喚起」を発信済み。JPCERT/CCは NetScaler（CVE-2026-8452、8/15）・Metabase（8/14）・8月Microsoft月例（8/12）を注意喚起。

## 4. 海外動向

- **境界・仮想化基盤への攻撃集中**: Citrix NetScaler（CVE-2026-8452、PoC公開）、VMware vCenter（公表5日後に悪用）、Fortinet、Cisco ASA/FTD と、境界機器・仮想化基盤の重大脆弱性が同時多発。「公表から悪用までの時間」が数日に短縮している。
- **クラウド鍵の漏えい**: CRMプロバイダBeaconが、漏えいしたAWSアクセスキーを原因に英国1,500慈善団体のデータ侵害を公表（8/13）。クラウドの認証情報・キー管理が引き続き弱点。
- **ランサムウェア**: 8/14に Cambria Law Firm・CF Supply・Compunnel 等が INC_RANSOM・Akira・Qilin 等に掲載。恐喝型が継続。

## 5. 安全確保支援士としての推奨アクション

1. **境界機器（NetScaler/Fortinet/Cisco）と仮想化基盤（vCenter）の緊急点検**: Citrix NetScaler は CVE-2026-8452 のPoC公開済み・悪用可能性高のため、Gateway/AAA構成を確認し即時更新（14.1-72.61 / 13.1-63.18 以降）。vCenterはBroadcomアドバイザリに従い即時更新。公表から数日で悪用される前提で対応を。
2. **Windows 8月月例の適用（継続）**: ワーム化し得るDNS Server RCE（CVE-2026-62878）、悪用中のafd.sysゼロデイ（CVE-2026-68820）を最優先。お盆明けの適用漏れを点検。
3. **認証情報保護を最優先課題に**: 侵入の8割が「盗まれたID」。フィッシング耐性のある多要素認証（パスキー）、パスワード使い回しの排除、リスト型攻撃対策（ログイン監視・レート制限）を顧客に強く推奨。ヨネックス事案が好例。
4. **「サポート詐欺」への従業員教育**: 偽の警告画面で電話・遠隔操作に誘導する手口が国内で被害拡大。AIツール・検索利用時のリスクとして、勉強会・社内教育に組み込む。「警告画面の電話番号にかけない」を周知。
5. **端末・データ持ち出し管理**: PC紛失による情報漏えい（東京ガス子会社事案）を踏まえ、端末の暗号化・持ち出しルール・紛失時対応手順を確認。
