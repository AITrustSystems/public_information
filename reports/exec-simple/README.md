# 経営者向け 簡易版 について

このフォルダには、経営者・個人事業主向けの**簡易版**レポートを格納します。要点を短時間で把握できるよう、やさしい言葉で3トピック＋「✅ CHECK!（自社確認ポイント）」＋「経営者の一言アクション」にまとめています。

- `daily/` … 日次（毎日 朝5時・日本時間）
- `weekly/` … 週次（毎週月曜 朝5時・前週分のまとめ）
- ファイル名: 日次 `YYYY-MM-DD.md` ／ 週次 `YYYY-Www.md`

より詳しく知りたい場合は、同じ日付の**本格版（詳しい版）** `../exec-full/` を参照してください。
