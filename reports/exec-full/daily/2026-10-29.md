# 経営者向け セキュリティレポート 2026-10-29

対象: 経営者・個人事業主の方（ITの専門知識は不要）
作成: AI Trust Systems株式会社 情報処理安全確保支援士

## エグゼクティブ・サマリー

本日の要点は次の3つです。

- **①延べ約2億6,000万人分**: 国の集計で、4月以降に不正アクセスで漏れた個人情報は、日本の人口の2倍を超えました。
- **②国への報告が急増**: 10月は半月だけで830件と、昨年度1年間の半分を超える報告がありました。
- **③会社のサーバーの土台にも弱点**: 仮想化ソフトやLinuxの弱点が悪用され、**攻撃の痕跡を消す**手口も見つかっています。

キーメッセージ：国が統計を公表して危機感を示し、対策の水準も引き上げようとしています。「**原因の型ごとの点検**」「**報告の手順**」「**記録（ログ）を残す仕組み**」の3点を整えてください。

## トピック1：漏えいは延べ約2億6,000万人分

### 何が起きたか
個人情報を監督する国の機関が、4月から10月半ばまでに報告された漏えいをまとめました。不正アクセスで漏れた個人情報は、**延べ約2億6,000万人分**です。同じ人が何度も数えられているため、実際の人数ではありませんが、規模の大きさを示しています。

### なぜ経営に関わるか
国は今後、企業に求める対策の水準を引き上げる方針です。被害を受けたときに「対策をしていたか」がこれまで以上に問われます。

### 確認すべきこと（✅ CHECK!）
- [ ] お客様の情報をどこに、どれだけ持っているか把握していますか？
- [ ] 使っていない古い情報を消していますか？
- [ ] 誰がお客様の情報を見られるか、決めて管理していますか？

## トピック2：国が示した「原因の型」で点検する

### 何が起きたか
国は、報告された漏えいの原因を9つの型に整理し、注意を呼びかけています。報道で分かっている主な型は次のとおりです。

- **弱点の放置**（ソフトの更新をしていない）
- **不正なログイン**（盗まれたパスワードなど）
- **グループ会社や海外拠点への攻撃**
- **クラウドサービスやアプリの裏側の窓口の悪用**

### なぜ経営に関わるか
これらは、今年の大型の被害の多くに当てはまります。自社と委託先を、この型ごとに点検するのが近道です。

### 確認すべきこと（✅ CHECK!）
- [ ] ホームページ・ネットショップ・社内のソフトの更新を放置していませんか？
- [ ] 管理者のアカウントに二段階認証を設定していますか？
- [ ] グループ会社・海外拠点・委託先の対策を確認していますか？
- [ ] クラウドやアプリの裏側の窓口から、他人の情報を取り出せないことを確認しましたか？

## トピック3：国への報告が急増、手順の確認を

### 何が起きたか
漏えいが起きたときの国への報告は、昨年度1年間で約1,250件でした。今年は4月から10月半ばで約2,100件、**10月だけで半月に830件**と急増しています。外部のクラウドやメール配信サービスが攻撃され、それを使う多くの会社が一斉に報告したことが大きな理由です。

### なぜ経営に関わるか
自社が攻撃されていなくても、**使っている外部サービスが攻撃されれば、自社も報告やお客様への連絡が必要**になることがあります。

### 確認すべきこと（✅ CHECK!）
- [ ] 漏えいのおそれが分かったとき、国への報告を担当する人を決めていますか？
- [ ] 報告の目安（知ってから3〜5日以内の速報）を知っていますか？
- [ ] 外部サービスの事故の連絡を受けたとき、自社の対応を判断する手順がありますか？
- [ ] お客様へのお知らせのひな形を用意していますか？

## トピック4：会社のサーバーの土台にも弱点、痕跡を消す手口も

### 何が起きたか
多くの会社でサーバーをまとめて動かすために使われている**仮想化ソフト（VMware）**と、サーバーの基本ソフト（**Linux**）の弱点が、実際に攻撃に使われていました。仮想化ソフトの弱点では、攻撃者が**自分の操作の記録（ログ）が残らないようにしていた**ことが分かっています。米国の政府機関も、急いで直すべき弱点に加えました。

### なぜ経営に関わるか
記録が残らなければ、**何をされたか分からず、被害の範囲も説明できません**。国も、記録を残して定期的に確認することを求めています。

### 確認すべきこと（✅ CHECK!）
- [ ] 社内のサーバー（仮想化ソフト・Linux）の更新を、IT担当者・委託先に確認しましたか？
- [ ] 重要なシステムの記録（ログ）を、別の場所に保管していますか？
- [ ] 記録を定期的に確認する担当者を決めていますか？

## トピック5：従業員の口座番号も漏れた

### 何が起きたか
大手コーヒーチェーンで、従業員・退職者の情報が漏れ、**口座番号**も含まれていたと報じられています。生命保険会社でも約38万件の漏えいが報じられるなど、大きな公表が続いています。

### なぜ経営に関わるか
社員の口座番号や住所が漏れると、**社員を狙った詐欺や、会社をかたるなりすまし**に使われます。社員の情報も、お客様の情報と同じように守る必要があります。

### 確認すべきこと（✅ CHECK!）
- [ ] 給与・人事のシステムに、二段階認証を設定していますか？
- [ ] 社員の口座番号などを見られる人を、必要最小限にしていますか？
- [ ] 退職した人の情報を、必要以上に残していませんか？

## 用語ミニ解説

- **延べ人数**：同じ人が複数回数えられた合計です。実際の人数より多くなります。
- **仮想化ソフト**：1台の大きなサーバーの中で、何台分ものサーバーを動かすためのソフトです。
- **ログ（記録）**：誰が、いつ、何をしたかの記録です。被害の範囲を調べるために欠かせません。

## 本日を踏まえた「経営者の3つの確認」

1. **原因の型ごとに点検する**（更新の放置、二段階認証、グループ会社・委託先、裏側の窓口）。
2. **報告の手順を決める**（担当者、3〜5日以内の速報、外部サービスの事故への対応）。
3. **記録を残し、社員の情報も守る**（ログの別保管と定期確認、人事・給与システムの守り）。
