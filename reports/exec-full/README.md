# 経営者向け 本格版（詳しい版）について

このフォルダには、経営者・個人事業主向けの**本格版（詳しい版）**レポートを格納します。

- `daily/` … 日次（毎日 朝5時・日本時間）
- `weekly/` … 週次（毎週月曜 朝5時・前週分のまとめ）
- ファイル名: 日次 `YYYY-MM-DD.md` ／ 週次 `YYYY-Www.md`

## 簡易版との違い

| | 簡易版（exec-simple） | 本格版（exec-full／このフォルダ） |
|---|---|---|
| ねらい | 要点を短時間で把握 | 背景・理由・具体策まで踏み込んで理解 |
| 分量 | 3トピック＋一言アクション | 5トピック前後＋詳しい解説・チェックリスト |
| 用語 | 専門用語は極力使わない | やさしい言葉のまま、必要に応じ用語ミニ解説を付す |

いずれも**経営者・非エンジニア向け**で、技術的な詳細（CVE番号・CVSS等）は専門家向けレポート（非公開）に委ねています。
