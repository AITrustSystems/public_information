# 経営者向け レポート（詳細版）について

このフォルダには、経営者・個人事業主向けのレポートのうち、**背景・理由・具体策まで踏み込んだ版**を格納します。

- `daily/` … 日次（毎日 朝5時・日本時間）
- `weekly/` … 週次（毎週月曜 朝5時・前週分のまとめ）
- ファイル名: 日次 `YYYY-MM-DD.md` ／ 週次 `YYYY-Www.md`

要点だけを短時間で把握したい場合は、同じ日付の**簡易版** `../exec-simple/` を参照してください。いずれも経営者・非エンジニア向けで、技術的な詳細（CVE番号・CVSS等）は扱いません。
