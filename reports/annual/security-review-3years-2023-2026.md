# セキュリティ動向総括レポート（2023年〜2026年前半・3年間）

セキュリティ専門家（情報処理安全確保支援士）向け
作成: 2026-07-25（Claude Code調査）

> 注記: ipa.go.jp / npa.go.jp 等一次情報への直接アクセスが制限された環境での調査のため、検索結果・二次解説記事に基づく。「未確認」表記の箇所は一次情報での確認を推奨。直近1年の詳細は `security-review-2025-2026.md` を参照。

---

## 1. 2023年：エッジ機器悪用の顕在化とLockBit全盛

- **MOVEit Transfer大規模侵害**（5月〜）: Cl0pがゼロデイSQLi（CVE-2023-34362）を悪用し、暗号化なしの窃取・恐喝を展開。被害は約2,700組織・9,300万人超。「ゼロデイ×一斉恐喝」モデルの原型。
- **名古屋港ランサムウェア**（7月4日）: LockBitが港湾統一システムNUTSを暗号化、全コンテナターミナルが約3日停止。侵入はVPN機器経由とみられる。港湾セキュリティ強化の契機。
- **Emotet活動再開**（3月）: OneNote添付・巨大Word文書による検知回避。以後大規模再開はなく、メール起点攻撃の主役交代の転換点。
- **3CXサプライチェーン攻撃**（3月末）: 北朝鮮Lazarusが正規アップデートを汚染。侵入起点も別ソフトの侵害という史上初の「二重サプライチェーン攻撃」。
- **Citrix Bleed（CVE-2023-4966）**（10月〜）: セッショントークン窃取でMFAバイパス。LockBit系がBoeing侵入に悪用（CISA/FBI合同勧告AA23-325A）。
- **LockBit全盛**: 年間リークサイト掲載約1,047件で最多（シェア約2割）。Royal Mail、TSMCサプライヤー等。
- **MGM Resorts / Scattered Spider**（9月）: ヘルプデスクへのビッシングで侵入。Q3で約1億ドルの損失。ソーシャルエンジニアリングの脅威を象徴。
- **国内**: セイコーグループがBlackCat被害（8月公表）。NTT西日本子会社で元派遣社員による約928万件持ち出し発覚（10月）— 内部不正リスクの象徴。

## 2. 2024年：国内大手の長期停止と摘発・障害の年

- **KADOKAWA/ニコニコ**（6月8日）: BlackSuitのランサム攻撃でニコニコ等が約2か月停止。漏えい確認254,241人、特別損失36億円。国内世論・経営層のリスク認識を大きく変えた事案。
- **Change Healthcare**（2月）: MFA未設定のリモートアクセスからALPHVが侵入、米医療決済網が麻痺。約2,200万ドル支払後にALPHVは出口詐欺で消滅。影響1億人超（米医療史上最大）。
- **Snowflake顧客侵害**（4〜6月）: インフォスティーラー由来の認証情報でMFA未設定テナントへ「正規ログイン」。約165顧客（Ticketmaster 5.6億人、AT&T等）。「認証情報の時代」を決定づけた。
- **CrowdStrike大規模障害**（7月19日）: Falcon設定更新不具合でWindows約850万台がBSOD、航空5,000便超欠航。「史上最大のIT障害」— セキュリティ製品自体が単一障害点になる教訓。
- **XZ Utilsバックドア**（3月29日発覚）: CVE-2024-3094（CVSS 10）。約2年かけてメンテナ権限を獲得する長期潜伏型OSSサプライチェーン攻撃。
- **LockBit摘発（Operation Cronos）**（2月19日）: 日本含む10か国共同でインフラ制圧・復号鍵押収。首謀者を特定・制裁。
- **エッジ機器ゼロデイの連鎖**: Ivanti Connect Secure（1月、CISA緊急指令ED 24-01）、Fortinet CVE-2024-21762（2月）、Palo Alto CVE-2024-3400（4月）。
- **国家支援型**: Salt Typhoonが米通信9社へ長期潜入（10月頃発覚）。Volt Typhoonの重要インフラ「事前配置」（最長5年潜伏）をCISAが警告（AA24-038A）。
- **国内**: イセトーのランサム被害（5月、8Base）で委託元の自治体・金融機関へ連鎖、計約307万人漏えい。JAXA侵害の詳細公表。岡山県精神科医療センター最大約4万人流出。証券フィッシング急増（2025年被害の前兆）。

## 3. 2025年：国内サプライチェーン直撃とAI悪用の本格化

- **証券口座乗っ取り**: 不正アクセス17,559件・不正売買7,393億円。リアルタイムフィッシングでMFA突破。日証協が10月にフィッシング耐性MFA必須化。
- **NTTコミュニケーションズ**（3月公表）: 法人17,891社の契約情報流出の可能性。
- **アサヒグループHD**（9月29日〜）: Qilinのランサム攻撃で受注・出荷停止、Q3決算発表延期、190万件超の漏えいの可能性、通期業績下方修正。
- **アスクル**（10月19日〜）: ランサムで受注・出荷全面停止。委託元の無印良品・ロフト等のECも連鎖停止。約74万件漏えい。
- **SharePoint「ToolShell」**（7月）: 未認証RCE（CVE-2025-53770等）が大規模悪用。300超の組織へ攻撃、中国系・ランサムアクターが関与。
- **Scattered Spider〜Salesforce恐喝**（4〜10月）: 英小売（M&S・Co-op）から保険・航空へ拡大。ShinyHuntersらとの連合がSalesloft Drift連携のOAuthトークンを悪用し700社超のSalesforceデータを窃取・恐喝。
- **RaaS勢力図の激変**（4月）: 最多だったRansomHubが突然消滅、アフィリエイトがQilin等へ移籍しQilinが最多に。
- **AI悪用の本格化**（11月公表）: 中国国家系GTG-1002による「初のAIオーケストレーション型スパイ攻撃」— AIが作戦の8〜9割を自律実行、約30組織を標的。

## 4. 2026年前半（概要）

- 暗号化なし恐喝（World Leaks等）とQilin等による大手攻撃が継続（Sysco、Novo Nordisk関連等の報告）。
- 国内は委託先・グループ会社経由の不正アクセス、ニチレイグループのランサム被害（7月、RansomHouse）、SharePoint攻撃キャンペーン（CVE-2026-58644等）、BEC深刻化。
- 詳細は年次レポート `security-review-2025-2026.md` を参照。

## 5. 3年間の構造変化（支援士が押さえるべき本質）

### (a) ランサムウェアのビジネスモデル変化
- 暗号化型 → **暗号化なしデータ恐喝**の定着（Cl0p/MOVEit 2023 → World Leaks 2026）。
- 摘発と離合集散の加速: LockBit摘発（2024年2月）→ ALPHV出口詐欺（2024年3月）→ RansomHub台頭→消滅（2025年4月）→ Qilin/Akira台頭。グループ数は増加（73→109）。
- **身代金支払率は2025年Q3に23%と史上最低**（Coveware）— バックアップ・復旧態勢の普及が交渉力に。

### (b) 初期侵入経路の変化
- メール（Emotet）→ **VPN・RDP経由**（警察庁統計で8割超）→ **エッジ機器ゼロデイ**（Citrix Bleed、Ivanti、ToolShell）→ **インフォスティーラー由来の正規認証情報**（Snowflake、証券乗っ取り）。
- 「境界の内側は安全」という前提が完全に崩壊。フィッシング耐性認証（パスキー）とゼロトラストへの移行が実務課題に。

### (c) サプライチェーン攻撃の常態化
- ソフトウェア供給網: 3CX（2023）→ XZ Utils（2024）→ npm Shai-Hulud・Salesloft Drift OAuth（2025）と毎年発生。
- 国内は「委託先・共用基盤」経由が主戦場: イセトー（2024）→ アスクル物流停止波及（2025）→ ニチレイ（2026）。委託先監督とBCPが経営課題に。

### (d) 生成AIの攻防
- 攻撃: ディープフェイクCFO会議で2,560万ドル詐取（Arup、2024年2月）→ AIフィッシング常態化 → AIが攻撃の大半を自律実行（GTG-1002、2025年11月）。
- 防御: SOC自動化・AIによる脆弱性発見が進展。AIシステム自体のリスク（プロンプトインジェクション等）も評価対象に。

### (e) 日本の法制度の変化
| 時期 | 制度 |
|---|---|
| 2022年4月〜 | 改正個人情報保護法の漏えい報告義務の運用定着 |
| 2024年5月 | 経済安全保障推進法・基幹インフラ事前審査制度の運用開始（未確認） |
| 2025年5月16日 | 重要経済安保情報保護活用法（セキュリティ・クリアランス）施行 |
| 2025年5月成立 | 能動的サイバー防御関連法（サイバー対処能力強化法等）。2026年4月1日サイバー通信情報監理委員会設置、主要部分は2026年10月1日施行 |
| 2026年7月10日 | 改正個人情報保護法成立（課徴金導入・AI開発向け同意緩和等、施行は2028年頃見込み） |

### (f) IPA情報セキュリティ10大脅威（組織編）の変遷
- 2024年版: ランサム1位（9年連続）・サプライチェーン2位
- 2025年版: ランサム1位（10年連続）・サプライチェーン2位、「地政学的リスクに起因するサイバー攻撃」が7位で初選出
- 2026年版: ランサム1位・サプライチェーン2位を維持、「**AIの利用をめぐるサイバーリスク**」が3位で初選出

## 総括

3年間で脅威は「メール起点・暗号化型ランサムウェア」から「**エッジ機器・認証情報起点のデータ恐喝とSaaS供給網攻撃**」へ移行した。国内では名古屋港（2023）→ KADOKAWA（2024）→ アサヒ/アスクル（2025）→ ニチレイ（2026）と**事業停止型被害が毎年発生**し、セキュリティは完全に経営・サプライチェーンの問題になった。2025年にはAIの攻撃利用が実戦段階に入り、日本は能動的サイバー防御法・改正個情法（課徴金）を含む法制度整備で対抗する構図となっている。

支援士としては、(1)エッジ機器と認証基盤の防御・侵害後対応、(2)委託先・SaaS連携を含むサプライチェーン管理、(3)フィッシング耐性認証への移行支援、(4)AI利用・AI攻撃の双方への備え、(5)新法制への顧客対応支援、の5点が今後の中核スキルとなる。
